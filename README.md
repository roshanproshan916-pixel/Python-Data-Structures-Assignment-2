## 📌 About the Project

This repository contains my **Python Fundamentals Assignment 2**, completed using Jupyter Notebook. The assignment focuses on understanding and implementing Python's core data structures and conditional statements through practical coding exercises.

The notebook includes commented code, examples, and explanations to demonstrate the concepts covered in the assignment.

## 🎯 Objectives

- Understand Python lists and their built-in methods.
- Create and manipulate dictionaries to manage student marks.
- Explore set properties, duplicate removal, and set operations.
- Apply conditional statements to classify performance scores.
- Improve problem-solving skills through hands-on Python practice.

## 📚 Topics Covered

### 1. Lists
- Creating lists of integers and strings
- Adding and removing elements
- Inserting and extending lists
- Sorting elements in descending order
- Finding maximum, minimum, and sum
- Accessing elements using indexing and slicing
- Reversing list elements

### 2. Dictionaries
- Creating a student marks dictionary
- Accessing student marks using keys
- Adding new student records
- Updating existing marks
- Using `keys()`, `values()`, and `items()`

### 3. Sets
- Creating sets and identifying duplicate removal
- Understanding why sets do not support indexing or item assignment
- Creating and comparing two sets
- Performing union and intersection operations

### 4. Conditional Statements
- Using `if`, `elif`, and `else`
- Validating scores within the range of 0 to 10
- Classifying scores into performance categories:
  - **Above Average:** Score greater than 7
  - **Average:** Score from 4 to 7, inclusive
  - **Below Average:** Score below 4
- Displaying appropriate feedback messages
